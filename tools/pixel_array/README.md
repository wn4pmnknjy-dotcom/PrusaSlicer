# STL 像素锁格阵列工具

Windows 小工具：把 STL 拖进窗口，设数量，自动按光固化屏幕像素“锁格”摆放到平台上，导出整盘 STL。

## 用法
1. 双击 `PixelArray.exe`，把一个或多个 STL 拖进窗口（或点“添加 STL…”）。
2. 选机型：2K（2560×1600，像素 0.035 mm）、4K（3840×2400，像素 0.0233 mm），或自定义。
3. 在“数量”里填每个零件要几个。需要指定行列时，选中零件点“阵列设置…”（或双击该行），填 X/Y 数量和间距。
4. 点“自动摆放”，右边预览平台俯视图。
5. 点“导出 STL…”，得到一个合并好的 STL。导入切片软件时请关闭“自动居中/自动摆放”。

## 摆放规则
- **最小位置**：每个零件绕 Z 轴转到外接矩形面积最小的角度（长边沿 X），已经摆正的零件不转。
- **像素锁格**：每个零件外接框左下角都落在像素边界上，所有平移都是像素整数倍，复制件的像素栅格完全一致。
- **复制件**：默认排成整齐阵列，节距 = 外接框 + 间距，向上取整到像素；一行按平台宽度尽量放满。勾选“复制件交错紧密排”后改为逐个找最靠左下的空位。
- **不同零件**：按占地从大到小，用像素占用图找最靠左下且不冲突的位置，可再转 90°。
- 零件之间至少保留“零件间距”，平台四周保留“边缘留白”。放不下的数量会提示。
- 导出坐标默认以平台中心为原点（屏幕分辨率是偶数，像素边界正好在 0 两侧对齐）。

## 开发
```
pip install -r requirements.txt pytest
python -m pytest tests
python main.py
```
GitHub Actions（`.github/workflows/pixel_array_exe.yml`）在 Windows 上用 PyInstaller 打包成单个 exe。
